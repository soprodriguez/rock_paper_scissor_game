Project: Rock, Paper, Scissors Game

Description:
This project is a simple command-line Rock, Paper, Scissors game. The user plays against the computer by choosing rock, paper, or scissors. The computer randomly selects its choice, and the program determines the winner based on the game rules.

The program includes error handling to make sure the user enters a valid option. If the user inputs an invalid word, the program will prompt them again until a correct choice is entered.

Language:
Python

Libraries Used:

random (for generating the computer’s choice)
